# Feature 033: Mehrsprachigkeit (i18n)

## Status: done

## User Story
Als nicht-deutschsprachiger Nutzer möchte ich die App in meiner Sprache nutzen können.

## Akzeptanzkriterien
- [ ] Deutsch (de) als Default-Sprache
- [ ] Englisch (en) als zweite Sprache
- [ ] Automatische Spracherkennung basierend auf Browser/System-Locale
- [ ] Manueller Sprachwechsel in Settings
- [ ] Alle UI-Texte übersetzt (Labels, Buttons, Fehler, Empty-States)
- [ ] Venue-Typ-Labels übersetzt (Kneipe/Pub, Bar/Bar, Biergarten/Beer Garden, etc.)

## Technische Notizen
- Flutter `intl` Package mit `.arb` Dateien
- `flutter_localizations` für Material-Widgets
- Generierte Locale-Klassen via `flutter gen-l10n`
- Hardcoded Strings extrahieren aus allen Widgets
