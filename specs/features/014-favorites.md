# Feature 014: Favoriten

## Status: draft

## User Story
Als Nutzer möchte ich Bars als Favoriten speichern können, damit ich sie schnell wiederfinden kann.

## Akzeptanzkriterien
- [ ] Herz-/Stern-Icon auf Venue-Detail zum Favorisieren
- [ ] Favoriten-Liste als eigener Screen oder Tab
- [ ] Favoriten werden lokal gespeichert (kein Account nötig)
- [ ] Favoriten-Marker auf der Karte hervorgehoben
- [ ] Favoriten exportieren/importieren (optional)
- [ ] Widget-Tests

## UI/UX
- Toggle-Icon in Venue-Detail (ausgefüllter/leerer Stern)
- Favoriten-Screen über Navigation erreichbar
- Favoriten-Marker in Gold/Gelb auf der Karte

## Technische Notizen
- SharedPreferences oder Hive für lokale Speicherung
- Favoriten als Liste von Venue-IDs
